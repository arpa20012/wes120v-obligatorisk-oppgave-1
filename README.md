# WES120V obligatorisk oppgave 1

Dette er et enkelt Vite-prosjekt laget i forbindelse med WES120V.

## Forutsetninger

Node.js og pnpm må være installert.

## Installering

Installer prosjektets avhengigheter med:

`pnpm install`

## Oppstart

Start utviklingsserveren med:

`pnpm dev`

Åpne adressen Vite viser i terminalen i nettleseren.
